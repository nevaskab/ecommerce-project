# Planner / Planejamento

## Português

O Cybertech Store foi criado como um projeto de estudo e portfólio para praticar desenvolvimento full-stack, principalmente React, TypeScript, integração com APIs, autenticação e persistência de dados.

### Objetivos

- Construir uma experiência de e-commerce responsiva e reutilizável.
- Separar responsabilidades entre componentes, páginas, contextos e serviços.
- Integrar um catálogo externo e uma API própria para dados do usuário.
- Praticar autenticação segura, modelagem relacional e internacionalização.
- Explorar um assistente de IA limitado ao catálogo e à navegação da loja.

### Escopo atual

O catálogo vem do DummyJSON; usuários, carrinho e wishlist são persistidos no PostgreSQL pelo backend Express/Prisma. O frontend suporta English e Português (Brasil). Checkout e pagamentos permanecem fora do escopo atual.

### Próximos passos

Testes automatizados, pedidos, checkout, pagamentos, validação mais completa de entradas e evolução da observabilidade do backend.

## English

Cybertech Store was created as a learning and portfolio project to practice full-stack development, especially React, TypeScript, API integration, authentication, and data persistence.

### Goals

- Build a responsive and reusable e-commerce experience.
- Separate responsibilities across components, pages, contexts, and services.
- Integrate an external catalog with a custom user-data API.
- Practice secure authentication, relational modeling, and internationalization.
- Explore an AI assistant constrained to the store catalog and navigation.

### Current scope

The catalog comes from DummyJSON; users, cart items, and wishlist items are persisted in PostgreSQL through the Express/Prisma backend. The frontend supports English and Brazilian Portuguese. Checkout and payments are currently out of scope.

### Next steps

Automated tests, orders, checkout, payments, stronger input validation, and improved backend observability.
